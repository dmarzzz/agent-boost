## Short introduction

Agent Boost adds private payments to Hermes. It runs locally, creates fresh wallet addresses, and keeps wallet keys out of model prompts. The current preview uses shielded Sepolia test payments. Private search and private inference are coming soon.

## Technical introduction

Agent Boost is a local MCP sidecar for Hermes. Kohaku handles wallet cryptography; Agent Boost handles live balances, payment plans, spending limits, approvals, and redacted results. The preview supports shielded Sepolia payments, with separately enrolled Shade Tree egress for explicit HTTPS reads. Private search and private inference are coming soon.

## Use these consistently

Lead with the tagline and immediately explain it with “Private payments for
Hermes.” Reserve “sidecar,” “MCP,” “Kohaku,” and “covered egress” for the
technical introduction, walkthrough, or answers to specific questions.

“Private identity” means fresh wallet accounts/addresses in this preview. Use
“fresh wallet addresses” when the reader has not already learned that meaning.

The reusable memory cues are the dark-mode phrase, the green switch, and keys
staying out of context. Repeat those; do not introduce a new slogan on every
surface.
